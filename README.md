# Zephyr OS 发布

本仓库只提供 Zephyr OS 的安装包、SHA256 校验文件和版本信息；源码独立维护。

[下载最新正式版](https://github.com/jinshance/zephyr-os-releases/releases/latest)

Windows x64：选择 Setup EXE 安装版，或完整免安装 ZIP。升级前保存内容并退出旧版，再覆盖安装；本地资料与个性化设置会保留。API Key 默认仅保存在运行内存。

从 v0.2.6 起，软件内检查更新使用本仓库。旧版需从上面的发布页手动安装一次 v0.2.6 或更新版本。

每个正式版本提供安装 EXE、免安装 ZIP、update-manifest.json 与 SHA256 校验文件。GitHub 自动生成的 Source code 压缩包只包含本发布仓库的说明文件，不是完整软件。
